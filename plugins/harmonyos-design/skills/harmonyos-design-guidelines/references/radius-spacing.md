# 圆角与间隔

## 圆角

同一功能层级、同类控件或容器保持相同圆角。圆角与视觉和功能层级通常正相关：顶层浮层大于中层卡片，中层卡片大于标签和小图标背景。

| 常用规格 | 典型场景 |
|---:|---|
| 4vp | 标签、角标、小型状态标识、迷你图标背景 |
| 8vp | 图片、图标、小容器、列表内模块、基础控件 |
| 16vp | 通知卡片、普通卡片、内容容器、中型面板 |
| 20vp | 按钮、菜单、选项卡、功能入口、高频控件 |
| 32vp | 半模态、大型弹出框、顶层浮层、重点容器 |

完整 `corner_radius_*` Token 读取 `design-tokens.json`。全量表并非每个 level 都存在，不得补齐缺失项。

## 间隔原则

- 优先使用固定基数的倍数，通常围绕 4vp、8vp 体系组织。
- 信息层级越高、独立性越强，间隔通常越大；同级与同类元素保持一致。
- 区分屏幕边缘、元素之间和文本之间三类间隔。
- 设备边距按设备选择，不要把手机 16vp 左右边距复制到所有终端。

## 多设备屏幕边距

| 设备 | 左右 | 顶部 | 底部 |
|---|---:|---:|---:|
| 手机 | 16vp | 36vp | 28vp |
| 折叠屏 | 24vp | 36vp | 28vp |
| 平板 | 32vp | 36vp | 28vp |
| 智慧屏 | 48vp | 27vp | 27vp |
| 智能穿戴 | 26vp | 20vp | 20vp |
| 电脑 | 40vp | 未提供 | 未提供 |
| 智能座舱 | 48vp | 未提供 | 未提供 |

## 常见场景

- 泛手机：卡片间 12vp；有明显边界的控件间较大间隔 16vp；普通控件间隔 8vp；主次文本上下 2vp、左右 8vp。
- 智慧屏：有明显边界的控件间较大间隔 24vp；普通间隔 12vp；较小间隔 8vp；文本段落层级依次可用 32、24、16、8、4vp。
- 智能穿戴：官方示例覆盖 12、6、8、26、16、12、6、2vp 等具体场景，使用时结合实际组件位置，不要仅按编号猜用途。
