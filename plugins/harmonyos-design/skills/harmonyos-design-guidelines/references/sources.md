## 更新规则

1. 用户要求“最新”时，重新读取相关官方 HTML 与 `.md` 页面。
2. 先比较 Token 名、设备列和主题列，再更新本地数据；不要只比较页面标题。
3. 官方正文、图片和全量表冲突时，记录冲突。数值交付优先引用明确的全量表，实际开发再核对目标 SDK 的资源或 API。
4. 不把博客、论坛或第三方复刻当成官方参数来源。
