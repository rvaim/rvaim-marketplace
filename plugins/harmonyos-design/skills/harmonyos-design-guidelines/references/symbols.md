# HarmonyOS Symbol

## 使用定位

HarmonyOS Symbol 是具备字体属性的系统功能图标。它能与文本基线对齐，随字体粗细连续变化，并通过资源名称在 `SymbolGlyph` 或 `SymbolSpan` 中使用。

- `SymbolGlyph`：用于独立图标，可设置字号、粗细、颜色渲染和动效。
- `SymbolSpan`：用于图文混排，共享基线、字号和字重等文本属性。
- 默认图标宽高与字号一致，例如 24vp 字号对应 24×24vp 图标。

## 颜色渲染

- `SINGLE`：只使用第一种用户颜色。
- `MULTIPLE_OPACITY`：使用一种颜色并按图层透明度渲染；默认第一层 100%、第二层 50%。
- `MULTIPLE_COLOR`：按图层顺序使用两种颜色；颜色多于图层时，多余颜色不生效。

## 动效

按同页明确列出的清单，支持出现、消失、弹跳、缩放、替换、快速替换、脉冲、可变颜色和禁用九种策略，默认无动效。官方正文前一句仍写“7 种动态效果”，与九项清单存在计数不一致；实现前以目标 SDK 的 API 枚举为准。

只在操作反馈、状态变化或数据传输等有明确含义的时机使用动效，不要让图标持续无目的运动。

## 图形规范

- 标准画布为 24×24vp，主体通常控制在 22×22vp 区域。
- 常规描边 1.5vp，端点使用圆头，断口宽度 1.3vp，外圆角 3vp，内圆角 1.5vp。
- 复杂图形可采用 1.3vp 描边并做视觉校正，但仍以共同几何基础为准。
- 导出必须包含外框线条，并使用 SVG 格式。
- 状态角标可使用圆形背板；面性角标无需背板时，按 8vp 规范绘制。
- 切断效果两侧留白，端口宽度 1.3vp，切面平直，斜线从左上到右下并保持 45°。

优先从官方 HarmonyOS Symbol 图标库查询资源名，不要自行创建一个与系统已有语义重复的图标。
