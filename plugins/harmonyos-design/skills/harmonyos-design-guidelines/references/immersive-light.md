# 沉浸光感

## 设计目的

沉浸光感把光作为塑造空间、传递反馈和引导注意的界面语言。材质通过扩散、折射、漫反射和动态透光形成前后景关联，使悬浮操作与内容在 Z 轴上分离，同时维持信息可读性。

优先在操作元素可能与内容重叠时使用，例如悬浮标题栏、底部操作区、临时浮层、半模态和弹出框。不要把它当作所有容器的默认装饰。

## 用户强度

- 强档：强化折射、粒子和空间光效，提升纵深与视觉张力。
- 均衡档：系统默认，在通透感、对比度和日常清晰度间平衡。
- 弱档：收敛光彩，提高核心信息在复杂背景上的对比与熟悉感。

系统会把应用定义的材质自动映射到用户选择的三档强度。应用只定义材质层级，不为三档分别编码。

## 五档材质

官方页面示意图给出五档：`ULTRA_THIN`、`THIN`、`NORMAL`、`THICK`、`ULTRA_THICK`。页面图中以 `Ultra_Thin`、`Thin`、`Normal`、`Thick`、`Ultra_Thick` 展示；代码中的最终大小写与枚举命名以目标 SDK API 为准。

## 场景映射

| 场景 | 推荐材质 | 配合方式 |
|---|---|---|
| 顶部悬浮组件 | `ULTRA_THIN` | 结合渐变模糊延展顶部内容空间 |
| 底部悬浮组件 | `THIN` | 结合渐变颜色蒙层延展底部内容空间 |
| 非常驻、可能在任意位置出现的浮层 | `THICK` | 优先保证复杂背景上的内容可读性 |
| 半模态或大型弹出框 | `ULTRA_THICK` | 为大面积、丰富内容提供更强可读性 |

官方场景表没有给 `NORMAL` 指定唯一场景，不要自行宣称它是某类组件的强制值。

## 审查重点

- 材质是否解决了内容重叠或空间分层问题？
- 不同背景下的文字、图标与控件边界是否仍然清晰？
- 材质是否随用户强度偏好自动变化？
- 顶部与底部是否分别采用合适的渐变辅助，而非同一套效果？
- 动态光场是否与触碰、滑动等交互一致，并避免干扰核心任务？
